# Figures

This folder contains the figures in the order they appear in the current draft, together with the scripts and files used to generate each figure.

> **Important:** Run the main workflow first before generating any figures. The workflow produces the required `dnds_output` directory used by the downstream analyses.

For **Figure 4 (heterogeneity analysis)**, the workflow intermediate alignment files are also required. These are taken from the `final_aln` intermediate output and used for the acute vs. chronic `vgrG` heterogeneity test.
