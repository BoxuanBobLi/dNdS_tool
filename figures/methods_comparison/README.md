# dN/dS Method Comparison

This folder contains two scripts used to compare dN/dS estimates generated by four different methods:

- `concatenated`
- `consensus_avg`
- `ancestral_avg`
- `PAO1PA14_ref`

## 1. Regression Analysis

The regression script compares **per-gene mean dN/dS values** between every pair of methods across the four conditions:

- `0_vs_0`
- `0_vs_1`
- `1_vs_0`
- `1_vs_1`

For each method pair, it:

- matches genes by VFG ID
- calculates the mean dN/dS for each gene
- computes Pearson correlation, Spearman correlation, slope, and intercept
- generates pairwise scatter plots
- writes a summary table
