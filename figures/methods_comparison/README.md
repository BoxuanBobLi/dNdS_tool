# dN/dS Method Comparison

This folder contains scripts used to compare dN/dS estimates generated by four different methods:

* concatenated
* consensus_avg
* ancestral_avg
* PAO1PA14_ref

## Requirements

Before running these scripts, make sure the dN/dS workflows for all four methods have been completed.

Each method should have a dnds_output directory containing:

0_vs_0/

0_vs_1/

1_vs_0/

1_vs_1/

## Run Order

### 1. Run the regression script first

The regression script requires the dnds_output directories from all four methods.

It:

* calculates per-gene mean dN/dS
* matches genes across methods
* compares every method pair
* calculates Pearson and Spearman correlations
* generates regression plots

Main outputs:

regression_summary.csv
plots/

The regression_summary.csv file is required by the next script.

### 2. Run the boxplot script second

The boxplot script requires:

regression_summary.csv

generated by the regression script.

It summarizes the correlation values across the four conditions for each method pair.

Main outputs:

pearson_r_boxplot.png
pearson_r_points.csv

## Workflow

dN/dS workflows for all 4 methods
