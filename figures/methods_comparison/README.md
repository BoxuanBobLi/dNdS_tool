# dN/dS Method Comparison

This folder contains two scripts used to compare dN/dS estimates generated by four different methods:

- `concatenated`
- `consensus_avg`
- `ancestral_avg`
- `PAO1PA14_ref`

## 1. Regression Analysis

The regression script compares **per-gene mean dN/dS values** between every pair of methods across the four conditions:

- `0_vs_0`
- `0_vs_1`
- `1_vs_0`
- `1_vs_1`

For each method pair, it:

- matches genes by VFG ID
- calculates the mean dN/dS for each gene
- computes Pearson correlation, Spearman correlation, slope, and intercept
- generates pairwise scatter plots
- writes a summary table

Main output:

```text
regression_summary.csv
plots/
````

The regression summary contains the correlation statistics used by the second script. 

## 2. Correlation Boxplot

Run the boxplot script **after the regression script**.

It reads:

```text
regression_summary.csv
```

and summarizes the Pearson correlation values across the four conditions for each of the six possible method pairs.

Each box represents one method pair, with the values from the four conditions contributing to the distribution.

Main outputs:

```text
pearson_r_boxplot.png
pearson_r_points.csv
```

To plot Spearman correlation instead, change:

```python
METRIC = "pearson_r"
```

to:

```python
METRIC = "spearman_rho"
```

> **Important:** The dN/dS workflows for all four methods should be completed first so that the required `dnds_output` directories are available.
