# dN Distribution Plot

This script compares the distribution of **dN values** between:

- `CladeA_vs_CladeA`
- `CladeA_vs_CladeB`

using the dN/dS result CSV files generated by the workflow.

## Input

The script reads all CSV files from the corresponding `dnds_output` folders and extracts:

- all valid `dN` values
- `dN` values from rows where `dN/dS = Inf`

## Output

The script generates two figures:

### `dN_values_distribution_sidepanels_ALL.png`

Shows the distribution of **all dN values**.

The main panel displays the overall distribution from `0–2.5` on a log-scaled y-axis. Two side panels zoom in on:

- `0–0.02`, where many low dN values are concentrated
- `0.90–1.10`, to inspect values around dN ≈ 1

### `dN_values_distribution_sidepanels_INF.png`

Shows the same comparison using only rows where **dN/dS is infinite**.

An infinite dN/dS value generally occurs when the synonymous substitution rate (`dS`) is zero while `dN` is non-zero. This plot helps examine whether these infinite ratios are driven by very small dN values, values near 1, or other parts of the dN distribution.

> **Important:** Run the main workflow first so that the required `dnds_output` directories and dN/dS CSV files are generated.
